Secure Preview PIN setup

Generate your Commissioner PIN verifier and session secret directly inside Safari, over HTTPS. The calculation runs in this browser: your PIN and generated values are not sent to the FFO server.

Checking secure browser…
Do not paste your PIN or generated secrets into ChatGPT, GitHub, screenshots or league chat. Enter each generated value only in Cloudflare Preview → Variables and Secrets as type Secret.

PBKDF2-SHA256, 210,000 iterations; 64 hexadecimal characters.
16 random bytes; 32 hexadecimal characters.
48 random bytes; 96 hexadecimal characters.

After generation

  1. Keep this Safari tab open while configuring Cloudflare.
  2. Open Cloudflare → Workers & Pages → dirtybirdstest → Settings → Preview → Variables and Secrets.
  3. Create three entries of type Secret with the exact names above. Copy and paste one value at a time, then save.
  4. A new Preview deployment is required before the Commissioner API shows ready: true. Production must remain unchanged.

If generation is blocked, this page reports the browser security problem instead of silently failing. The browser keeps these outputs only in this tab; it does not persist them across reloads.
